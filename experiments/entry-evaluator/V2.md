# V2: Physical sensitivity screening

## Purpose

V1 established numerical consistency for the reduced-order evaluator under fixed
physical assumptions. V2 asks a different question:

> Does the working-fluid ranking survive reasonable changes in the physical
> assumptions that dominate this low-fidelity model?

V2 does **not** assign probabilities to the ranges below. It performs a
deterministic Latin-hypercube screening across declared intervals. The output is
a map of conditional model behavior, not a reliability estimate or mission
qualification.

## New radiative-validity metric

V1 reported the fraction of nonzero-heating time steps inside the nominal
Tauber-Sutton range. That metric can be misleading because weak and strong
heating steps count equally.

V2 also integrates radiative energy:

```text
E_rad,total = integral(q_rad dt)
E_rad,valid = integral(q_rad dt) over steps inside nominal validity
f_rad,valid = E_rad,valid / E_rad,total
```

The same diagnostic is reported for the integrated forebody radiative power.
This directly answers what fraction of the modeled radiative energy is produced
where the implemented correlation declares itself nominally valid.

The existing time-step fraction remains for compatibility.

## Default study

The supplied `physical-sensitivity.yaml` creates 64 Latin-hypercube scenarios
plus one explicit nominal scenario. Four fluids are evaluated in every scenario,
for 260 independent trajectories.

The default sampled ranges are:

| Parameter | Range |
| --- | ---: |
| Entry velocity | 11-15 km/s |
| Flight-path angle | -20 to -10 deg |
| Nose radius | 0.5-2.0 m |
| Modeled cooled area | 6-18 m2 |
| Convective angular exponent | 0.5-2.0 |
| Radiative angular exponent | 0.5-2.0 |
| Wall emissivity | 0.70-0.95 |
| Wall areal heat capacity | 50-200 kJ/m2/K |
| Convective correlation scale | 0.90-1.10 |
| Radiative correlation scale | 0.70-1.30 |
| H2 fixed chemistry outlet ceiling | 650-850 K |

The chemistry ceiling only affects the default hydrogen case because the other
three cases use `chemistry.mode: disabled`.

These are screening ranges, not validated uncertainty distributions. In
particular, nose radius and cooled area are varied independently even though a
real vehicle geometry would couple them.

## Why these heating scale ranges are explicit

The repository still uses engineering correlations, not a coupled
nonequilibrium shock-layer solution.

A NASA entry-system study describes Sutton-Graves stagnation heating as
typically accurate to roughly 5-10% for blunt bodies and states a nominal Earth
Tauber-Sutton range of approximately 10-16 km/s, 0.3-3 m nose radius and the
associated density/altitude interval:

https://ntrs.nasa.gov/api/citations/20060004824/downloads/20060004824.pdf

The original Tauber-Sutton publication reports maximum differences of roughly
20-30% against independent computations:

https://ntrs.nasa.gov/search.jsp?R=19910048758

Later NASA hyperbolic-entry work found radiative-heating structural uncertainty
of approximately +34% / -24% for higher-fidelity simulations in studied cases:

https://ntrs.nasa.gov/archive/nasa/casi.ntrs.nasa.gov/20110013360.pdf

V2 therefore uses ±10% convection and ±30% radiation as transparent screening
bands. They are not confidence intervals and should be replaced by
case-specific uncertainty models when higher-fidelity aerothermodynamics is
introduced.

## Sampling

For every parameter, the interval is split into N equal strata. Exactly one
sample is drawn from each stratum and the strata are independently permuted
between parameters. The seed is fixed, making the study exactly reproducible.

This gives one-dimensional range coverage without the combinatorial explosion
of a full Cartesian product.

## Fair fluid comparison

Every sampled physical scenario is replayed for every fluid with:

```text
vehicle.couple_coolant_mass_to_trajectory = false
coolant.available_mass_kg = null
```

Thus each fluid sees the same trajectory assumptions within one scenario.

V2 deliberately does not yet solve the next system-level fixed point:

```text
coolant inventory -> vehicle mass -> trajectory -> heating -> coolant inventory
```

## Run

From `experiments/entry-evaluator`:

```bash
python -m unittest discover -s tests -v
python run_physical_sensitivity.py \
  --workers 16 \
  --output-dir physical-v2
```

Use `--samples` or `--seed` to override the study file without editing it.

## Outputs

| File | Meaning |
| --- | --- |
| `manifest.json` | exact ranges, seed, scenarios, source hashes, versions |
| `runs/run-*.json` | every individual trajectory result |
| `all_runs.csv` | flattened per-fluid results |
| `scenario_summary.csv` | one matched comparison per physical scenario |
| `scenario_summary.json` | same matched comparisons in JSON |
| `physical_sensitivity_report.json` | aggregate ranking, radiation and sensitivity report |

## Interpretation

The report does not require hydrogen to win.

For matched H2/water scenarios it reports:

```text
H2-better count
water-better count
unresolved count (default +/-1% band)
H2-better fraction
min / p05 / median / p95 / max of M_H2 / M_water
```

It also reports the best fluid across all four fluids when all four runs are
comparable, scenario status counts, energy-weighted radiative-validity
statistics and Spearman rank correlations between each sampled input and:

```text
M_H2 / M_water
M_H2
M_water
```

A high correlation is a sensitivity diagnostic, not proof of causality.

## Remaining limitations

V2 inherits V1 physics unless explicitly varied. It still has no:

- rarefied/free-molecular heating model;
- reacting boundary layer;
- transpiration/blowing reduction of incoming heat;
- porous-media pressure-drop model derived from geometry;
- finite pump/tank mass model;
- trajectory guidance or 6-DOF dynamics;
- geometry-calibrated surface heat-flux distribution;
- coupled nonequilibrium radiation/flow solution;
- structural or ablation model.

The correct next escalation depends on what V2 shows. If ranking is insensitive
to most assumptions but strongly controlled by the H2 chemistry ceiling, the
chemistry/residence-time model becomes the priority. If it is controlled by
radiation assumptions, higher-fidelity aerothermodynamics becomes the priority.
