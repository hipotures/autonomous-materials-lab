# V3: Cross-model Earth aeroheating comparison

## Purpose

V1 established numerical convergence. V2 showed that the fluid ranking survives
the declared physical-sensitivity ranges under the legacy Sutton-Graves /
Tauber-Sutton heating model. V3 asks whether that conclusion survives a second
Earth-entry engineering correlation family.

V3 adds the Brandis-Johnston 2014 stagnation-point correlations as a selectable
backend and evaluates both backends on exactly the same V2 scenarios.

This is cross-model verification, not flight validation.

## Backends

### legacy

The existing backend is unchanged:

- Sutton-Graves stagnation convection;
- Tauber-Sutton stagnation radiation;
- the existing Knudsen transition multiplier.

Select it with:

```yaml
heating:
  backend: legacy
```

### brandis_johnston_2014

For 3 <= V < 9.5 km/s:

```text
q_conv [W/cm2] =
    7.455e-9 * rho^0.4705 * V^3.089 * Rn^-0.52
```

For 9.5 <= V < 17 km/s:

```text
q_conv [W/cm2] =
    1.270e-6 * rho^0.4678 * V^2.524 * Rn^-0.52
```

For 9.5 <= V < 17 km/s:

```text
q_rad [W/cm2] = 3.416e4 * Rn^a * rho^1.261 * f(V)

a = min(3.175e6 * V^-1.80 * rho^-0.1575, amax)

amax = 0.61   for 0 < Rn <= 0.5 m
       1.23   for 0.5 < Rn <= 2 m
       0.49   for 2 < Rn <= 10 m

f(V) = -53.26 + 6555 / (1 + (16000 / V)^8.25)
```

Inputs are SI: `rho` in kg/m3, `V` in m/s and `Rn` in m. The code
explicitly converts the published W/cm2 result to W/m2.

The implemented nominal validation envelope is:

```text
rho: 1e-5 .. 5e-3 kg/m3
Rn:  0.2 .. 10 m
V:   3 <= V < 17 km/s convection
V:   9.5 <= V < 17 km/s radiation
continuum_factor >= 0.999
```

The equations are from Brandis and Johnston, *Characterization of
Stagnation-Point Heat Flux for Earth Entry*, AIAA 2014-2374. The two convective
branches are reproduced in later NASA engineering work. Open technical
literature reproduces the radiative relation and the stated density/radius
domain.

Sources:

- https://doi.org/10.2514/6.2014-2374
- https://ntrs.nasa.gov/api/citations/20240014309/downloads/aiaa_aviation_2025_Hyatt_Johnson.pdf
- https://aerospacerepository.org/wp-content/uploads/2024/05/HiSST-2024-46.pdf
- https://iaaspace.org/wp-content/uploads/iaa/Scientific%20Activity/conf/pdc2015/IAA-PDC-15-05-02.pdf

## No hidden extrapolation across velocity branches

The Brandis-Johnston backend returns zero outside the published velocity
branches:

- convection below 3 km/s or above 17 km/s;
- radiation below 9.5 km/s or above 17 km/s.

It does not silently substitute the legacy model. This makes missing model
coverage visible in the integrated diagnostics.

The same rarefied-flow multiplier used by V1/V2 is still applied. Thus V3 does
not solve the missing free-molecular/transitional heating problem.

Density values outside the nominal validation interval can still be evaluated
algebraically when the formula is defined, but are marked invalid. Radiative
nose-radius values outside the published `amax` branches are not extrapolated.

## New evaluator diagnostics

The summary now includes:

```text
heating_backend

convective_valid_heat_load_mj_m2
convective_energy_valid_fraction
vehicle_convective_valid_heat_mj
vehicle_convective_energy_valid_fraction
convective_correlation_valid_fraction

radiative_correlation_active_valid_fraction
```

The older radiative validity fields remain for compatibility.

For the legacy backend, no explicit Sutton-Graves nominal validity envelope was
encoded in V0/V1. Therefore the new convective-validity fractions are reported
as unavailable rather than claiming a validation domain that the implementation
does not define.

## Cross-model run

The V3 runner reuses `physical-sensitivity.yaml`, including the same seed,
Latin-hypercube ranges and nominal point. By default:

```text
65 scenarios
x 4 fluids
x 2 heating backends
= 520 trajectories
```

Run:

```bash
python -m unittest discover -s tests -v

python run_heating_model_comparison.py \
  --workers 16 \
  --output-dir heating-model-v3
```

## Outputs

| File | Meaning |
| --- | --- |
| `manifest.json` | exact sources, seed, scenarios, backends and versions |
| `runs/run-*.json` | individual trajectory results |
| `all_runs.csv` | all 520 flattened results |
| `model_pairs.csv` | Brandis-Johnston vs legacy for each fluid/scenario |
| `backend_ranking.csv` | H2/water ranking for each backend/scenario |
| `heating_model_report.json` | aggregate cross-model report |

For each fluid, the report gives distributions of:

```text
M_BJ / M_legacy
E_incident,BJ / E_incident,legacy
q_peak,BJ / q_peak,legacy
```

For H2 versus water it reports each backend separately and the shift:

```text
(H2/water)_BJ - (H2/water)_legacy
```

It also counts any ranking reversal.

## Interpretation

A stable H2/water ranking across both backends would be stronger evidence that
the result is not an artifact of the original Tauber-Sutton closure. It would
not establish that either correlation is correct at every point along the
trajectory.

A large absolute heat-load difference with a stable fluid ratio would indicate
that the ranking is mostly controlled by the fluid enthalpy/chemistry model.
A large ranking shift would make aeroheating model fidelity the immediate
priority.

After V3, the next likely escalation is the existing H2 ignition-delay table and
residence-time model, unless V3 instead shows strong heating-backend sensitivity.
